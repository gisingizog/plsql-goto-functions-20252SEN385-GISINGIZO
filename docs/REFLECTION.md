# Reflection

## Employee Management System

This project helped me understand how PL/SQL can be used to manage and process employee information in a database.

I used PL/SQL GOTO statements to perform different employee-related tasks such as salary classification and salary review. I also learned that although GOTO can control the flow of a PL/SQL program, it should be used carefully because excessive use can make code difficult to understand. The same salary review was therefore rewritten using normal IF, ELSIF, and ELSE statements.

I also created stored functions for the Employee Management System. These functions calculate annual salary, years of service, employee tax, and department names. I learned that functions are useful when the same calculation or operation needs to be performed repeatedly.

Exception handling was also included in the project. For example, when an employee does not exist, the program handles the NO_DATA_FOUND exception rather than terminating unexpectedly.

Finally, I used the functions directly in SQL queries to produce an employee payroll report. This showed me how PL/SQL functions can work together with SQL to produce useful information from database records.

Overall, the project improved my understanding of GOTO statements, functions, exception handling, and the use of PL/SQL functions in SQL.
